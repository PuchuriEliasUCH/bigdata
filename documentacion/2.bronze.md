# Bronze: respuestas crudas y estado de la ingesta

Bronze guarda cada registro tal como lo devolvió la API, junto con el estado de cada lote y el plan de
cuotas. No limpia ni deduplica nada. Es la fuente de verdad: Silver y Gold se pueden reconstruir desde
aquí sin volver a llamar a las API.

## Propósito

| Propiedad | Cómo se cumple |
|---|---|
| **Crudo** | Cada registro se guarda como el texto JSON original (`record_json`). |
| **Recuperable** | Silver se reconstruye desde Bronze cuando cambia su esquema ([`_ensure_schema_version`](../src/spark_pipeline.py)). |
| **Auditable** | Cada lote tiene un JSON con su consulta, estado, contadores y lista de páginas. |

## Entradas

Las páginas que devuelven los ingestores ([ingesta](1.ingesta.md)). Solo las escriben
[`BatchStateStore.write_raw_page`](../src/openalex_ingest.py) y
[`BatchStateStore.write_metadata`](../src/openalex_ingest.py), compartidos por ambas fuentes.

## Estructura en disco

```text
data/bronze/
├── .pipeline.lock                     bloqueo flock entre ejecuciones
├── plans/
│   ├── openalex.json                  clave + totales y cuotas por año
│   └── scopus.json
├── batch_metadata/
│   ├── initial-<marca>-<hex>.json     lote OpenAlex, fase inicial
│   ├── incremental-<marca>-<hex>.json lote OpenAlex, fase incremental
│   └── scopus-<marca>-<hex>.json      lote Scopus (una ventana)
├── openalex/<lote>/page-000001.parquet ...
└── scopus/<lote>/page-000001.parquet ...
```

`<marca>` es la hora UTC de creación (`%Y%m%dT%H%M%S%fZ`) y `<hex>` ocho caracteres aleatorios
([`_batch_id`](../src/openalex_ingest.py)).

## Proceso

1. El ingestor crea el JSON del lote con estado `running` antes de pedir la primera página.
2. Por cada página con registros escribe `page-NNNNNN.parquet` en un temporal y lo reemplaza
   atómicamente.
3. Actualiza el JSON del lote (contadores, cursor u offset, lista de páginas) con la misma técnica.
4. Al terminar o pausarse, escribe el estado final o de pausa.

El orden "página primero, estado después" hace que el estado nunca apunte a una página inexistente.

### Esquema de una página

Una fila por registro ([`write_raw_page`](../src/openalex_ingest.py)), Parquet con compresión zstd
nivel 9:

| Columna | Tipo | Contenido |
|---|---|---|
| `batch_id` | string | Lote al que pertenece la página. |
| `page_number` | int32 | Número de página dentro del lote, desde 1. |
| `record_index` | int32 | Posición del registro dentro de la página, desde 0. |
| `record_json` | string | Registro original serializado: un *work* de OpenAlex o una entrada de Scopus. |

Silver deriva de `page_number` y `record_index` un orden determinista,
`record_order = (page_number − 1) × 1000 + record_index`. Silver también lee páginas JSON heredadas de
versiones anteriores y lotes que mezclan ambos formatos ([`_load_records`](../src/spark_pipeline.py)).

### Metadatos de un lote

| Campo | Fuente | Significado |
|---|---|---|
| `batch_id`, `source`, `mode` | Ambas | Identidad; `mode` es `initial` o `incremental`. |
| `status`, `stop_reason` | Ambas | Estado del ciclo de vida y motivo de la última parada ([tabla de estados](1.ingesta.md#ciclo-de-vida-de-un-lote)). |
| `target_records`, `record_count`, `page_count` | Ambas | Objetivo del lote, registros y páginas escritos. |
| `raw_page_dir`, `raw_page_files` | Ambas | Carpeta y lista de páginas, relativas a `bronze/`. |
| `created_at`, `updated_at` | Ambas | Marcas UTC. `created_at` se copia a Silver como `ingested_at`. `completed_at` solo existe en OpenAlex. |
| `filter` | OpenAlex | Filtro exacto de la línea, incluido `publication_year:<año>`. |
| `next_cursor`, `last_page_record_count` | OpenAlex | Cursor para continuar; tamaño de la última página. |
| `credits_remaining`, `next_attempt_at`, `http_status` | OpenAlex | Créditos leídos al iniciar; hora a partir de la cual reintentar; último error HTTP. |
| `query`, `base_query` | Scopus | Consulta de la ventana y consulta del año (`... AND PUBYEAR = <año>`). |
| `next_offset`, `total_results` | Scopus | Offset para continuar; total que informa la API para la ventana. |
| `rate_limit`, `rate_remaining`, `rate_reset`, `next_attempt_at`, `http_status` | Scopus | Encabezados `X-RateLimit-*` y espera por cuota. |
| `frozen_from`, `frozen_at` | Ambas | Solo en lotes congelados: estado previo y hora. |

### Planes

`plans/<fuente>.json` contiene `{"key": {...}, "plan": {"totals": {...}, "quotas": {...}}}`
([`save_plan`](../src/quotas.py)). `totals` es el total que la API informó por año al planificar; Gold
lo usa como denominador de la fracción muestreada.

## Salidas

| Salida | Consumidor |
|---|---|
| Páginas Parquet | Silver ([`_load_batch_dataframe`](../src/spark_pipeline.py)). |
| `batch_metadata/*.json` | Ingestores (reanudación), Silver (selección de lotes), compactación (fuente y año del lote), notebook de calidad. |
| `plans/*.json` | Ingestores (cuotas), Gold (`plan_total`), notebook de calidad (fracción muestreada). |

## Garantías y límites

| Se garantiza | No se garantiza |
|---|---|
| Cada página escrita está completa y es legible por Spark. | Ausencia de duplicados: el mismo registro puede estar en dos lotes (reinicios desde el último cursor u offset completo). |
| El estado de un lote refleja las páginas ya escritas. | Que la muestra de un año sea aleatoria: sigue el orden de la API (relevancia en OpenAlex, fecha de carga en Scopus). |
| Las credenciales no se escriben en ningún archivo. | Que Bronze sea un histórico completo de cada API: es una muestra acotada por cuotas. |
| Un lote terminal no vuelve a cambiar. | Integridad de todas las páginas al reconstruir Silver: solo se comprueba que existan los metadatos. |

No se debe inspeccionar ni publicar el contenido de las páginas sin autorización: son datos de gran
tamaño obtenidos bajo los términos de cada API.

## Cómo se pasa a Silver

[`_terminal_metadata`](../src/spark_pipeline.py) selecciona los lotes que Silver puede leer:

```text
lote elegible  ⇔  status ∈ TERMINAL_STATUSES[source]  y  page_count > 0
```

| Fuente | Estados terminales para Silver |
|---|---|
| OpenAlex | `completed`, `completed_target`, `completed_exhausted`, `quota_exceeded` (heredado), `failed`, `frozen` |
| Scopus | `completed`, `completed_target`, `completed_exhausted`, `result_window_reached`, `failed`, `frozen` |
| Sin `source` | Solo `completed`, `completed_target`, `completed_exhausted` |

`quota_exceeded` es terminal en OpenAlex (el código actual ya no lo escribe y los lotes antiguos nunca se
reanudan) pero no en Scopus, que sí lo reanuda. Un lote pausado no entra hasta que la ingesta lo complete
o se congele. Los elegibles se ordenan por `created_at` y `batch_id`, y Silver procesa cada uno una sola
vez.

Sobre los 4 712 lotes OpenAlex `quota_exceeded`: 4 698 no tienen páginas (con
`stop_reason=insufficient_credits`); los creó la versión anterior del código, que abría un lote nuevo
en cada ejecución sin créditos. Los 14 restantes tienen 44 000 registros y están en Silver.

Para la cobertura frente a la API conviene usar Silver (registros únicos) y no los conteos de Bronze,
que incluyen duplicados.
